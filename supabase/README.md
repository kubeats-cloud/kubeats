# supabase

Database sources of truth for the project.

```
supabase/
  migrations/    SQL migrations, applied in filename order
```

`migrations/0001_init.sql` — schema, Row Level Security policies, triggers and
seed data — is authored separately (Phase 1) and drops in here.

Nothing in this folder is generated by the Next.js app; the app only ever reads
the database through the Supabase clients in `src/lib/supabase/`.
